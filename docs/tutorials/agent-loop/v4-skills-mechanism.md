# v4: 스킬 메커니즘 (Skills Mechanism)

**모듈식 지식 주입 및 런타임 동적 스킬 확장**

에이전트에게 필요한 모든 도구와 지침을 시스템 프롬프트에 미리 다 넣으면 컨텍스트 토큰이 낭비되고 모델의 집중도가 떨어집니다.

v4 스킬 메커니즘은 특정 전문 작업(예: PDF 처리, 코드 리뷰, MCP 구축 등)이 필요할 때만 선언된 **스킬(Skills / `SKILL.md`)** 패키지를 동적으로 로드하고 주입하는 구조입니다.

---

## 스킬 파일 구조 (Agent Skills Spec)

```text
skills/
├── agent-builder/
│   ├── SKILL.md (스킬 메타데이터 & 실행 지침)
│   ├── references/ (참조 가이드 문서)
│   └── scripts/ (자동화 헬퍼 스크립트)
├── code-review/
│   └── SKILL.md
└── pdf/
    └── SKILL.md
```

---

## 런타임 동작 절차

1. **스킬 감지**: 등록된 스킬 디렉토리의 YAML 메타데이터(`name`, `description`)를 읽어 기본 에이전트에 등록
2. **요청 매칭**: 사용자의 질문에 해당 스킬이 필요하면 `use_skill` 도구 호출
3. **지침 주입**: `SKILL.md` 문서의 세부 실행 절차 및 가이드를 현재 컨텍스트에 동적으로 결합 후 실행

---

## 결론 및 에이전트 루프 진화 요약

| 버전 | 핵심 메커니즘 | 해결하는 문제 |
|:---|:---|:---|
| **v0** | Bash 실행 & 재귀 | 최소 코드로 완벽한 기능 통합 |
| **v1** | 모델 기반 도구 선택 | 동적 Tool Call 및 관찰 피드백 루프 |
| **v2** | Todo 리스트 계획 수립 | 긴 태스크 수행 시 목표 이탈(Drift) 방지 |
| **v3** | 서브에이전트 위임 | 컨텍스트 오염 방지 및 탐색 분리 |
| **v4** | 동적 스킬 주입 | 런타임 모듈식 지식 확장 |
